# Weekly classics — the SEO seed

Each one becomes `/books/<slug>` (server-rendered, cached, with the phonetic map) and a
newsletter issue. Adding one: a lightly normalised excerpt (2–5k words, a chapter) in
`server/data/samples/<slug>.txt` plus an entry in `index.json`. Public domain only, from
Project Gutenberg, attribution kept. Order follows what schools assign and what people search
for.
